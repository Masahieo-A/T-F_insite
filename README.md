# 校内陸上大会 記録管理・順位集計

校内陸上大会向けの、競技一覧・記録入力・順位計算・チーム得点集計を一体化したWebアプリです。

## 画面

- 競技一覧（開始時刻別）
- 組別結果／全体順位／実力帯別順位
- チーム総合得点と得点取引
- スマートフォン記録入力
- 記録入力時のチーム別選手選択（短距離5組、各組A・B・C各1名）
- フィールド各チーム5名・1人3試技と最高記録の自動採用
- 110mハードル3組目保存後の総合順位マスキング
- 教員パスワードによる総合順位・エントリ登録・大会管理の保護
- 大会管理（状態、選手、エントリー、記録訂正、監査ログ）

### 大会管理の編集機能

- 「チーム設定」でDB上の固定ID（A・B・C）を保ったまま表示名を変更
- 「競技管理」で種目名と開始時刻を行ごとに変更
- 「エントリー編集」で現在データ入りCSVテンプレートをダウンロード
- 編集済みCSVを取り込み、種目・選手・エントリーを一括更新
- 種目ごとに出場者の差し替え、追加、削除
- すべての変更を監査ログへ記録

CSVテンプレートの列:

`種目ID / 種目名 / 開始時刻 / 組 / レーン・試順 / 選手No / 氏名 / カナ /
学年 / 性別 / チームID / 所属 / 地域 / 実力帯 / 得点対象`

一括取り込みでは、CSVに含まれる種目のエントリーをCSV内容で置き換えます。
選手を別の選手へ差し替えた枠は、旧選手の記録が誤って残らないよう、その枠の記録を削除します。

## NANS風UI

`Desktop/校内大会/sample集/sample` のモックHTMLをゴールデンマスターとして解析し、次の値とDOMパターンを直接再利用しています。

- 青ヘッダー `#3d73cc`
- 表ヘッダー `#244f96`
- 淡青の交互行 `#e9f7fd`
- 罫線 `#c9c9c9`
- 選択中の緑 `#84bb44`
- 下線付きの青リンク、灰色のDNS/DNF/DQ/NM行、密度の高い固定レイアウト表

モックCSSからの意図的な差分は、スマートフォンで表を横幅いっぱいに収めるための
`width: 100%; min-width: 0; table-layout: fixed;` です。モックに含まれていた
`min-width: 760px` は390pxで横スクロールを起こすため採用していません。

## 計算

`lib/ranking.ts` に副作用のない関数として分離しています。

- 記録文字列のサニタイズと正規化
- トラック昇順／フィールド降順
- 同順位（競技順位方式）
- DNS、DNF、DQ、NMの順位除外
- 全体順位
- 種目順位点（PBボーナスなし）
- チーム総合同点時の1位数・2位数比較

表示文字列（`1:03.87`、`5m42`）と計算値（`63.87`、`5.42`）は分離しています。

## データモデル

`lib/domain.ts` で次のエンティティを分離しています。

`athletes` / `teams` / `events` / `entries` / `heats` / `results` /
`scoreRules` / `scoreTransactions` / `auditLogs`

## 教員認証

教員用パスワードの平文はリポジトリへ保存しません。SHA-256ハッシュをVercelのサーバー専用環境変数 `TEACHER_PASSWORD_HASH` に設定します。認証後はHttpOnly・SameSite=Strictの署名付きCookieを使用します。

## 保存方式

端末内はIndexedDBへ保存し、オンライン時は `/api/state` へ同期します。現在のAPI保存先は
サーバーランタイムのメモリであり、永続データベースではありません。大会本番で複数端末から
永続利用する場合は、認証と永続DBへの置換が必要です。
